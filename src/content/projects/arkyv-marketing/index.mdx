### Teaching Revit to engineers

As part of introducing Arkyv's engineering team to the Revit UI that architects actually work in, I ran an internal hands-on Revit training - walking through building a full house model start to finish, in the order an architect actually works, with Arkyv's own Revit plug-in switched off so engineers would learn the underlying Revit mechanics before the tool that automates them. I wrote a companion two-part reference: one page on core concepts (Actions, Parameters, Views, Sheets), and one walking through the full build sequence step by step, tying each stage back to the same Elements, Types, and Shared Parameters that Arkyv's compliance checks and Revit add-in read from and write to.
